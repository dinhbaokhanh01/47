# CodeGym Career Landing Page (Material Design)

Landing Page cho chương trình **CodeGym Career** được xây dựng theo phong cách **Material Design** sử dụng thư viện **MDBootstrap**.

## Nội dung trang nguồn
Dựa trên nội dung thực tế từ: https://codegym.vn/codegym-career/

## Công nghệ sử dụng
- HTML5
- CSS3 (Custom + MDBootstrap)
- JavaScript (jQuery)
- Bootstrap 4.5
- MDBootstrap 4.19.1 (Material Design for Bootstrap)
- Font Awesome 5
- Google Fonts (Roboto)

## Cấu trúc thư mục
```
codegym-career-landing/
├── index.html          # Trang chính
├── css/
│   └── style.css       # CSS tùy chỉnh
├── js/
│   └── script.js       # JavaScript tùy chỉnh
└── README.md
```

## Các section chính
1. **Navbar** – Cố định, responsive, Material Design
2. **Hero Section** – Banner lớn với CTA
3. **Stats** – 20 tuần | 100% có việc | 6-12tr lương | 45 ngày cam kết
4. **Tổng quan** – Giới thiệu chương trình
5. **Lợi ích** – 6 card lợi ích nổi bật
6. **Lộ trình** – 3 module học tập
7. **Cam kết việc làm** – 100% hoàn học phí
8. **Testimonials** – Phản hồi học viên
9. **Form đăng ký tư vấn** – Call to Action
10. **Footer** – Thông tin liên hệ & liên kết
